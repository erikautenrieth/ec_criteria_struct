Inclusion Criteria:
Need for long-term oral anticoagulation;
Patient [AND] has provided written informed consent.

Exclusion Criteria:
Need for long-term oral anticoagulation;
Drug-eluting stent implantation [AND] within 3 months prior to TAVI procedure;
Bare-metal stent implantation [AND] within 1 month prior to TAVI procedure;
Allergy [OR] intolerance to aspirin [OR] clopidogrel.
Drug-eluting stent implantation [AND] within 3 months prior to TAVI procedure;
Bare-metal stent implantation [AND] within 1 month prior to TAVI procedure;
Allergy [OR] intolerance to (N)OAC [OR] clopidogrel.
</EDITED_CRITERIA>
