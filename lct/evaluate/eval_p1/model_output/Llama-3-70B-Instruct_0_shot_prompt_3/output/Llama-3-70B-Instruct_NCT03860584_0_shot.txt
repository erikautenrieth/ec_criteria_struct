Here is the edited version of the inclusion and exclusion criteria with the logical operators [AND], [OR], [NOT] inserted:

Inclusion Criteria:
  -  Serum Glucose [OR] 100-126 mg/dl
  -  Waist C >89/102 cm; F/M [AND] with waist measurement
  -  Serum HDL-C: <50/40 mg/dl; F/M [AND] with HDL-C level
  -  Serum TG: >150 mg/dl [OR] elevated triglyceride level
  -  BP >130/85 mmHg [AND] with blood pressure measurement
  -  Serum Endotoxin >25 EU/ml [OR] elevated endotoxin level

Exclusion Criteria:
  -  [NOT] Stable body mass (±2 kg over prior 3-mo) [OR] weight fluctuation
  -  [NOT] Non-vegetarian
  -  Food allergies [OR] lactose intolerance
  -  User of dietary supplements [OR] probiotics (within past 1-mo) [NOT] supplement-free
  -  Pregnancy [OR] lactation [OR] changes in birth control (within 6-mo) [NOT] hormonal stability
  -  Any gastrointestinal disorders [OR] chronic gastrointestinal issues
  -  Chronic diarrhea [NOT] normal bowel function
  -  Smoker [NOT] non-smoker
  -  Excess alcohol (>2 drinks/d) [NOT] moderate alcohol consumption
  -  Excess aerobic exercise (>5 h/wk) [NOT] regular physical activity
  -  Recent antibiotic [OR] anti-inflammatory agent use [NOT] medication-free
  -  BP >140/90 mmHg [NOT] normal blood pressure
